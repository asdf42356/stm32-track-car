# 基于 STM32 的自动行驶小车

> 全国大学生电子设计竞赛作品 · 桂林信息科技学院 · 曹炘宇 / 林贵娇 / 苏卓伦

## 项目简介

以 STM32F103C8T6 为核心的两轮差速小车，融合 MPU6050 六轴传感器与 8 路灰度巡线传感器，在指定操场型赛道上自动行驶。系统用卡尔曼滤波估计偏航角，配合偏航角 PID、编码器差速校正和巡线 PID 构成「惯性导航 + 巡线跟随」双模态控制；针对赛题四个任务分别设计了控制流程。

## 控制方案

| 环节 | 实现 |
| --- | --- |
| 偏航角估计 | MPU6050 陀螺仪角速度积分 + 卡尔曼滤波（Q / R 参数见 `main.c` 顶部） |
| 航向控制 | 偏航角 PID，输出左右轮差速 |
| 里程校正 | TIM2 / TIM4 正交编码器计数，补偿左右轮速差 |
| 巡线控制 | 8 路灰度（74HC4051 多路复用）→ 加权位置 → 巡线 PID |
| 任务切换 | 上电后按键选择任务，蜂鸣器 + LED 提示，随后自动校准零偏 |

四个任务：任务一 A→B 纯惯性导航、遇黑线停车；任务二 / 任务三 惯性导航与巡线混合控制跑完一圈；任务四 高速巡线 + 圆弧搜索完成三圈。

## 硬件配置

| 模块 | 型号 / 引脚 |
| --- | --- |
| 主控 | STM32F103C8T6，72 MHz |
| 电机驱动 | TB6612：AIN1 PA4、AIN2 PA5、PWMA PA6；BIN1 PA2、BIN2 PB1、PWMB PA7；STBY PA3 |
| 编码器 | 左轮 TIM2（PA0 / PA1）、右轮 TIM4（PB6 / PB7），正交解码 |
| 姿态传感器 | MPU6050，I2C2：SCL PB10、SDA PB11 |
| 巡线传感器 | 8 路灰度经 74HC4051 复用：OUT PA11，通道选择 A0 PB13 / A1 PB12 / A2 PB14 |
| 人机交互 | 任务按键 PB3 / PB4 / PB5 / PA8，蜂鸣器 PB0，板载 LED PC13 |
| 调试串口 | USART1，PA9 / PA10，115200 8N1 |

## 代码结构

```
main.c       主流程、卡尔曼滤波、偏航角 / 巡线 PID、四个任务的控制逻辑
motor.c/h    TB6612 双路电机驱动（TIM3 PWM，1 kHz）
encoder.c/h  编码器接口（TIM2 / TIM4 编码器模式）
mpu6050.c/h  MPU6050 I2C2 驱动，含总线恢复与超时保护
stm32f10x_conf.h  标准外设库配置
1.uvprojx    Keil MDK 工程文件
```

## 编译与烧录

- 工具链：Keil MDK 5 + STM32F1xx_DFP 2.2.0 + ARM CMSIS 5.0.1
- 打开 `1.uvprojx`，目标器件 STM32F103C8，直接 Build 后用 ST-Link 下载

> 注意：工程中标准外设库与启动文件以绝对路径引用 Keil Pack（`D:\cunfang\keil\ARM\PACK\...`）。换到别的电脑时，需要在 `Options for Target → C/C++ → Include Paths` 以及工程文件组中把这些路径改成本机 DFP 安装位置。

## 操作说明

上电后串口输出 `Press: PB3=T1 PB4=T2 PB5=T3 PA8=T4`，按下对应按键选择任务；蜂鸣器与 LED 提示后进入陀螺仪零偏校准，校准完成即开始行驶，行驶结束停车。
